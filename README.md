# Agentic OS

Showcase site for [agentic-design-pipeline](https://github.com/tirsistris/agentic-design-pipeline): a replay of one real run of the pipeline on the task "collect feedback from chats and turn it into a prioritised roadmap" — every artifact the agents passed along, from brief to screens.

Live: https://agentic-os-weld.vercel.app

## Run it

```bash
npm install
npm run dev   # http://localhost:3000
```

Next.js (App Router), TypeScript. The run's artifacts live in `content/run/`.
